Bedrock Pack Manager

Install Minecraft Bedrock add-ons into your world or server folder. Everything runs in your browser and nothing is uploaded anywhere.

Make a backup of your world before making changes.

Loading the pack manager, this takes a few seconds the first time…

1 Open your server folder

Pick the folder that holds worlds, behavior_packs, and resource_packs.

2 Pick a world

3 Choose what to do
